# LSTARENGY — Open Sports Projection Research

Reverse-engineering research of the LineStar DFS projection system
(<https://www.linestarapp.com/>), with a verifiable, documented plan
to build an open sports projection system.

## GitHub Pages Site

➡️ **[Open the live documentation site](https://buffedlizard55-lab.github.io/LSTARENGY/)**

The site is a clean, single-page reference covering:

- Full feature inventory of LineStar (main tools, research, live, news)
- All 13 sports supported (NFL, NBA, MLB, NHL, WNBA, PGA, UFC, NASCAR, NCAAF, NCAAB, CFL, LoL, CS:GO)
- Verified data inputs (player history, matchups, Vegas odds, weather, injuries, lineups, salaries, ownership, sentiment)
- Publicly stated methodology and the four issued US patents (US 9,751,010; 9,744,450; 10,478,721; 11,660,533)
- Paywall breakdown ($39.99/month, $239.99/year)
- A 6-phase open build plan using free/public data and open-source libraries
- Limitations and legal flags for review
- Every claim linked to an official verified source
